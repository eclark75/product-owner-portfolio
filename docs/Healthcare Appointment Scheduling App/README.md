# Healthcare Appointment Scheduling App

## Overview

The Healthcare Appointment Scheduling App is a Product Owner portfolio project that demonstrates the end-to-end product management process for a modern healthcare scheduling platform.

This project includes product vision, product requirements, roadmap planning, sprint planning, Jira backlog management, and Confluence documentation. It showcases how Agile and Scrum practices can be used to deliver value while improving the patient appointment scheduling experience.
